## 4. Olası Değişikliğin Olgusal Anlamı

cdpilot ajan komutlarında stdout bir TTY'ye bağlı olmadığında (pipe/yönlendirme) veya MCP oturumu altında kompakt JSON (`separators=(',', ':')`) ve doğrudan UTF-8 (`ensure_ascii=False`) çıktısına geçilmesi durumunda, tam sayfa gözlem çıktılarında (`agent observe`) model bağlamına giren o200k token yükü medyan %42,13 (İngilizce sayfalarda %39,30–42,13; Türkçe sayfada %47,81; Japonca sayfada `\uXXXX` patlamasının ortadan kalkmasıyla %63,43) oranında azalmaktadır; eylem farkı çıktılarında (`agent act` diff) ise medyan token tasarrufu %27,16 (%20,35–35,58) düzeyindedir. Terminalde doğrudan etkileşimli insan kullanımı (`sys.stdout.isatty() == True`) için `indent=2` okunabilirliği korunurken, programmatic ve MCP tüketiminde (d) biçimine geçilmesi her gözlem adımında 4.000 ila 29.000 token tasarruf sağlamaktadır.
