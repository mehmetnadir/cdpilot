## Önceliklendirme

Bench V1'de düşük puanın iki ana sebebi:
1. **Behavioral entropi yok**: idle, scroll-pause, micro-jitter eksik → bot pattern'leri tetikliyor
2. **Session continuity yok**: temiz CDP session her seferinde aynı parmak izi profili veriyor

v0.9 her ikisini de attack ediyor — TLS'e dokunmadan.

## Feature: Session Warming (Behavioral Idle)

### Sözleşme
```
cdpilot warm <host>      # session warming — host'a "casually" bağlan
cdpilot idle <ms>        # behavioral idle (random scroll/mouse mikro-hareket)
cdpilot warm-and-go <url># warm + idle 2-5s + navigate (tek komut)
```

### Mekanizma
`warm`:
1. Host'un favicon, robots.txt, vs gibi "soft" endpoint'lerini fetch et (3-5 request, 200-500ms aralıklarla)
2. `Page.navigate` + `domcontentloaded` bekle (henüz hedef sayfa değil — anasayfa)
3. 2-5s "human-ish" idle → mouse perlin walk + 1-2 micro-scroll
4. Hedef URL'e geç

`idle <ms>`:
- MIN 800ms — bot gibi anlık tepki vermez
- Mouse: perlin noise yörünge (5-10 nokta, easing ile)
- Scroll: 1-3 küçük scroll (40-200px, ease-out)
- Klavye: yok (insanların 90%'ı bilgi ararken klavye'ye az dokunur)

### Bench beklentisi
- IP behavioral (CreepJS, fingerprint.com behavioral score): +8-12% kazanım
- Cloudflare Bot Score: muhtemel düşüş (0.99 → 0.6-0.8)
- DataDome: orta etki (DataDome'un asıl gücü TLS + JS challenge)

### Dahili API
- `behavioral.py` modülü — `idle()`, `perlin_walk()`, `human_scroll()`, `warm()`
- CDP: `Input.dispatchMouseEvent`, `Input.synthesizeScrollGesture`, `Runtime.evaluate`

## Feature: Sticky Session (Cookies + LocalStorage + TLS-cache)

`cdpilot stealth on` + `cookies safe-list` + per-host TLS session resumption:

- Chrome'un built-in TLS session cache'i zaten var → exit yapmadan kullan
- Aynı target için ikinci ziyaret %30+ daha "tanıdık" görünür (handshake atlanır)
- Implementation: process'i kapatmayıp `disconnect` ile session pool'da tut

### Sözleşme
```
cdpilot session pin <host>     # bu host için process'i ayrı tut, exit'te de yaşat
cdpilot session list           # pinned host'lar
cdpilot session evict <host>   # zorla kapatma
```

### Bench beklentisi
- Stateful target (booking, e-commerce login flow): +5-8%
- Stateless target (basic detection): no change

## Feature: Adaptive Backoff (Re-tune on Detection)

Adaptive escalation (v0.5.2+) zaten var. v0.9'da geri besleme:

- Per-host detection memory (`~/.cdpilot/detection-log.json`)
- Aynı host'a 3 kez bağlanıp 3 kez block alıyorsa: otomatik `idle = 2x`, `warm = on`
- Başarı oranı izlemesi: 7 günlük sliding window
- Toplam: bot olmadığını _öğrenir_

## Yapılmayanlar (v0.9'da değil)

- **TLS spoof / BoringSSL fork**: Etik+legal riskli, v1.0'a kadar yok. Honest disclaimer kalmaya devam.
- **Proxy auto-rotation**: Kullanıcı kendisi yönetir (proxy pool zaten v0.7'de geldi).
- **Captcha auto-solve via plugins**: 2captcha/anti-captcha bridge mevcut (v0.6.0), genişletmeye gerek yok.
