# Day 026 — T4 Stealth Engineering

## Topic
Keyboard jitter simulation

## Tweet 1/4 — Hook
Your bot types "password123" with exactly 50ms between every keypress. Every single one. Behavioral analysis flags this in the first word. Human fingers aren't metronomes — why is uniform delay still the default?

## Tweet 2/4
Real typing has natural variance: adjacent keys on QWERTY (like 'a' → 's') are faster than reaching keys ('a' → 'p'). Inter-key intervals follow a roughly log-normal distribution, not Gaussian. Average around 100-180ms, standard deviation ~40ms, with occasional 400ms+ pauses.

## Code snippet (tweet 3/4)
```python
import asyncio, random

async def human_type(cdp, text):
    for char in text:
        # Log-normal distribution — matches real human timing data
        delay = random.lognormvariate(4.5, 0.6) / 1000  # ~90ms mean
        await cdp.send("Input.dispatchKeyEvent", {
            "type": "keyDown", "text": char
        })
        await asyncio.sleep(max(0.025, delay))
```

## Tweet 4/4 — Anchor
Uniformity is a bot signal. Chaos is human. Add occasional 300-600ms pauses (thinking) and a rare 1-2s break (distracted). The variance is the point — not the specific numbers.
