# Day 014 — T8 Hot Take

## Topic
Headless detection is dead (as a binary concept)

## Tweet 1/5 — Hook
Running Chrome with `--headless` in 2026 is a flag. Every major bot-detection vendor checks for the absence of a dozen window properties that headless omits by default. Is it time to admit that "headless vs headful" is a dead binary?

## Tweet 2/5
Chromium's new headless mode (`--headless=new`, introduced in Chrome 112) is materially better. It shares the same renderer as headful Chrome. Most naive property checks fail against it. But it still leaves behavioral traces — event timing, scroll physics, focus handling.

## Tweet 3/5
The real tell isn't a flag. It's behavior. Real users move mice with human-curve acceleration. They scroll with momentum. They focus inputs before typing. A headless browser that never jiggles a pixel is an outlier no matter how many properties you patch.

## Tweet 4/5
