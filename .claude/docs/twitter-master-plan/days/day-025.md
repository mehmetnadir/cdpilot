# Day 025 — T3 AI Agents

## Topic
Local-LLM browser control

## Tweet 1/5 — Hook
Cloud LLMs are great until you hit a $500 bill for "browsing" a website, or your API rate-limits a 3am automation run. What if your browser agent ran entirely offline?

## Tweet 2/5
Setup: cdpilot + Ollama running Llama 3.1:8b locally. Use `cdpilot health` JSON output as the agent's world state, pipe DOM snapshots via `eval-batch`, and route actions back via `cdpilot click`/`cdpilot fill`. No API calls. No data leaving your machine.

## Tweet 3/5
Latency on a decent GPU: ~200-400ms per reasoning step. Compare that to 300-800ms for GPT-4o API roundtrips plus network overhead. For structured extraction tasks (not open-ended reasoning), local models are competitive.

## Tweet 4/5
Tradeoffs: local models hallucinate CSS selectors more often (less training data on real DOM patterns). Mitigation: always validate the returned selector against the AXT before executing. cdpilot's `a11y` command gives you a reference tree to ground the model.

## Tweet 5/5 — Anchor
Offline agents aren't a future thing. Anyone who cares about data sovereignty, per-request API cost, or 3am rate-limit failures is already doing this. The tooling just got good enough.
