# Day 007 — T7 History

## Topic
First browser automation tools

## Tweet 1/4 — Hook
Selenium was genuinely great in 2004. Then came HtmlUnit — fast because it skipped rendering entirely. Until JS complexity ate it alive and HtmlUnit became a glorified regex engine. Remember debugging a browser that didn't actually exist?

## Tweet 2/4
WebDriver tried to standardize, but "ready state" is meaningless in a React app. Puppeteer brought CDP to the masses in 2017 but added another layer of abstraction. Every generation trades control for convenience and then complains about flakiness.

## Tweet 3/4
Now we're in the agent era. Stealth isn't a feature — it's table stakes. Selenium failed here because it told the browser it was being controlled, literally, at the protocol level. "navigator.webdriver = true" was baked in.

## Tweet 4/4 — Anchor
The wheel turns. We're back to the metal: raw CDP, zero deps, surgical control. History repeats as cycles of abstraction and then revolt. Is the WebDriver model finally done?
