# Day 004 — T4 Stealth Engineering

## Topic
navigator.hardwareConcurrency override

## Tweet 1/4 — Hook
Anti-bot scripts check `navigator.hardwareConcurrency`. Running on a 64-core server but your UA says MacBook? And this value returns 64? Instant flag. Why are we leaking our infrastructure through a single JS property?

## Tweet 2/4
You can't just delete it. You override to a believable value — 4 or 8, matching the spoofed UA. But the timing matters: if the site reads this property before your patch script runs, you're already flagged.

## Tweet 3/4
cdpilot patches this via `Page.addScriptToEvaluateOnNewDocument` — fires before any page JS runs. Smart no-op: we only override if the value looks wrong. Avoids the defineProperty call itself being a tell.

## Tweet 4/4 — Anchor
If you're hitting 403s on sites that feel too easy, audit your hardware leaks first. `hardwareConcurrency`, `deviceMemory`, `platform` — three lines of JS that can fingerprint your entire infrastructure.
