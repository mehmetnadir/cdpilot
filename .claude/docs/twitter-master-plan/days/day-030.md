# Day 030 — T1 Foundations

## Topic
Input.dispatchMouseEvent — anatomy of a real click

## Tweet 1/5 — Hook
`element.click()` is not a click. It fires the click event directly, skipping mousedown, mouseenter, mousemove, and mouseup. Half the JS on the modern web listens to those events. Clicking without them triggers nothing and gets you flagged. 

## Tweet 2/5
A real mouse click is a sequence: `mousemove` to coordinates → `mousedown` (button pressed) → hold for ~50-100ms → `mouseup` (button released) → `click` event fires. Skip any step and you break click handlers that check for prior events.

## Code snippet (tweet 3/5)
```python
async def real_click(cdp, x, y):
    # Dispatch full event sequence
    for event_type in ["mouseMoved", "mousePressed", "mouseReleased"]:
        await cdp_send("Input.dispatchMouseEvent", {
            "type": event_type,
            "x": x, "y": y,
            "button": "left" if event_type != "mouseMoved" else "none",
            "clickCount": 1 if event_type == "mousePressed" else 0
        })
        if event_type == "mousePressed":
            await asyncio.sleep(0.06)  # human hold time
```

## Tweet 4/5
Also: coordinates matter. Clicking the exact pixel-center of an element is a bot signal. Real users click slightly off-center, within the clickable bounds. cdpilot randomizes click position within the element's bounding box by default.

## Tweet 5/5 — Anchor
Automation is easy. Emulation is hard. The gap between "it works" and "it doesn't get blocked" is entirely in these details — the events your framework fires for you invisibly, or doesn't.
