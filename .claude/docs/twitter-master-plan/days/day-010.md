# Day 010 — T3 AI Agents

## Topic
Stagehand integration basics

## Tweet 1/4 — Hook
Stagehand is impressive for high-level agent logic. But it can send 50k+ tokens of DOM noise to the LLM because it doesn't always prune the tree before passing it. How much of your agent's API bill is literally `<div class="wrapper">` nesting?

## Tweet 2/4
The fix: use cdpilot as the extraction layer under your agent framework. Raw CDP gives you the accessibility tree, targeted DOM queries, and `eval-batch` for bulk reads — without Stagehand's full-page serialization overhead.

## Tweet 3/4
The split: LLM handles reasoning and action planning. cdpilot handles browser execution. You pass the AXT snapshot (clean, semantic) to the LLM; it returns an action; you execute it over CDP. No 50k-token DOM serialization in the loop.

## Tweet 4/4 — Anchor
Building an agent? Start with the browser interface, not the LLM. How much of your prompt is wasted markup that the model ignores anyway?
