# Day 012 — T5 E2E Testing

## Topic
Async-await retry logic

## Tweet 1/3 — Hook
```
while (true) {
  try { return await page.find(sel) }
  catch { await sleep(100) }
}
```
Stop. This is how most retry logic is written and it's garbage. Wastes CPU, makes tests non-deterministic, and hides the real timing problem. There's a better model.

## Tweet 2/3
CDP has native events. `Page.loadEventFired`. `DOM.childNodeCountUpdated`. `Network.loadingFinished`. Listen for the state change instead of polling for it. The browser tells you when it's ready — if you bother to listen.

## Tweet 3/3 — Anchor
cdpilot's `wait-for-text` uses a rAF-throttled MutationObserver. It resolves the millisecond the text appears, uses zero CPU while waiting, and handles streaming content (LLM outputs, live updates). Sleep loops are technical debt.
