# Day 013 — T6 Performance & Scale

## Topic
Headless memory footprint — real numbers

## Tweet 1/3 — Hook
Headless Chrome memory: ~120MB browser process + ~80MB per renderer tab. At 50 concurrent tabs: 4GB+ before your code does anything. How are you handling memory spikes when you need to run 100+ instances?

## Tweet 2/3
Two models, very different outcomes:
- 50 separate Chrome processes: ~6GB RAM, 50x startup overhead
- 1 Chrome + 50 contexts (cdpilot pool): ~1.2GB RAM, ~3x faster spin-up

`Target.createBrowserContext` is the only sane model for scale. One process, N isolated execution environments.

## Tweet 3/3 — Anchor
cdpilot's efficient mode (visuals off, image blocking, no CSS paint) drops per-context memory another ~30%. We've tested 100 parallel contexts on an 8GB VPS. It's not comfortable but it works — and that's the point.
