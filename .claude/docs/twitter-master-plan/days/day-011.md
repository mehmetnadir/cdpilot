# Day 011 — T4 Stealth Engineering

## Topic
Canvas fingerprinting basics

## Tweet 1/5 — Hook
Canvas fingerprinting: the site renders a hidden image, reads the pixel values, hashes them. Every GPU renders slightly differently — sub-pixel antialiasing, driver-level color math, font hinting. The hash is your machine's ID. VPN doesn't help here.

## Tweet 2/5
Naive countermeasures fail in two ways. Block canvas entirely → immediate flag (legit browsers don't block it). Return a static image → the hash is too perfect, another flag. Anti-bot systems have seen every obvious move.

## Code snippet (tweet 3/5)
```javascript
// Inject per-session consistent noise into canvas reads
const orig = CanvasRenderingContext2D.prototype.getImageData;
CanvasRenderingContext2D.prototype.getImageData = function() {
  const data = orig.apply(this, arguments);
  // Same seed per session → consistent fingerprint, not caught
  data.data[0] ^= sessionNoiseSeed & 0xFF;
  return data;
};
```

## Tweet 4/5
The noise has to be session-consistent. If your canvas fingerprint changes between calls on the same page, that's itself a detection signal. cdpilot seeds the noise from the browser context ID — stable per session, different across sessions.

## Tweet 5/5 — Anchor
You can't block fingerprinting. You have to participate and blend in. Are you returning a believable fingerprint or making yourself an outlier?
