# Day 024 — T2 Anti-Bot Wars

## Topic
Cache fingerprint clearing

## Tweet 1/3 — Hook
"Always start with a clean profile" is standard automation advice. But clearing *everything* — including HSTS preload, shader cache, and common asset cache — makes you look like a bot that spawned from nothing. Real browsers have baggage. Do you know how much to clear?

## Tweet 2/3
A genuine user's browser has a warm cache: React bundles, Google Fonts, shared CDN assets. These cache hits affect network timing patterns. A cold cache on every request is a statistical outlier. cdpilot's context isolation cleans cookie/storage scope without touching the shared browser-level cache — the right balance.

## Tweet 3/3 — Anchor
The tradeoff table: rotating IPs + same cache fingerprint = cross-IP linkability. Clearing everything = fresh bot signal every time. Persistent cache + isolated cookies = closest to a real returning user. `Network.clearBrowserCache` is a scalpel, not a default.
