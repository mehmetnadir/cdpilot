# Day 023 — T1 Foundations

## Topic
Runtime.getProperties — traversing remote objects

## Tweet 1/4 — Hook
Stop using `eval()` to pull data from React/Vue apps. It injects code into the page, triggers CSP violations, and is trivially logged by any anti-bot that monitors `Runtime.evaluate` calls. There's a cleaner way to read app state.

## Tweet 2/4
`Runtime.getProperties` lets you walk the JS object graph from the outside. Get a remote handle to `document.querySelector('#root')`, then traverse the `__reactFiber$` tree property by property — no JS injection, no eval, no page modification.

## Code snippet (tweet 3/4)
```python
# Traverse React fiber tree via remote object handles
async def find_state(object_id, target_key="memoizedState"):
    props = await cdp_send("Runtime.getProperties", {
        "objectId": object_id, "ownProperties": True
    })
    for prop in props["result"]:
        if prop["name"] == target_key:
            return prop["value"].get("value")
        if prop["value"].get("objectId"):
            found = await find_state(prop["value"]["objectId"])
            if found: return found
```

## Tweet 4/4 — Anchor
This is how cdpilot reads deeply nested app state without touching the page. No eval. No inject. No trace in the JS execution log. The browser process exposes the object graph — you just have to ask the right way.
