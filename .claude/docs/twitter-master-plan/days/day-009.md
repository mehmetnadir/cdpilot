# Day 009 — T2 Anti-Bot Wars

## Topic
Sec-CH-UA client hints

## Tweet 1/3 — Hook
`Sec-CH-UA: "Chromium";v="124", "Google Chrome";v="124"`. Browsers send this by default now. If your UA string says Windows but your `Sec-CH-UA-Platform` says Linux, that's an instant flag. Are you auditing your outbound headers or just the UA string?

## Tweet 2/3
Client hints are the new UA. They're opt-in from the server side (via `Accept-CH` header), but browsers send the basic set regardless. Spoofing the UA string is 20% of the job. The hints have to match, and they have to be intercepted at the network layer, not the JS layer.

## Tweet 3/3 — Anchor
Most devs hit a Cloudflare wall, add a UA string, and wonder why they're still blocked. The headers tell the truth. cdpilot syncs your UA with the correct hint set on every request. Same browser, same story.
