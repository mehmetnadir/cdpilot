# Day 016 — T6 Performance & Scale

## Topic
Network.getResponseBody chunks

## Tweet 1/4 — Hook
Most browser libs fall over when you try to scrape a 50MB JSON response — they buffer the entire body into memory before you see a byte. Why are we still doing full-body buffering in 2026?

## Tweet 2/4
cdpilot uses the CDP `IO` domain for chunked response streaming. Instead of `Network.getResponseBody` returning everything at once, we pipe the stream handle through `IO.read` in 64KB chunks. Your Python process stays lean while data flows through.

## Code snippet (tweet 3/4)
```python
# Chunked response streaming via CDP IO domain
handle = await cdp_send("Network.getResponseBody", {"requestId": req_id})
# stream handle gives you IO.read access
while True:
    chunk = await cdp_send("IO.read", {"handle": handle, "size": 65536})
    process(chunk["data"])
    if chunk.get("eof"):
        break
```

## Tweet 4/4 — Anchor
Combine this with efficient mode (images/CSS blocked, visual feedback off) and you're running pure data pipelines. The browser becomes a headless HTTP client with a JS engine bolted on. That's the right abstraction.
