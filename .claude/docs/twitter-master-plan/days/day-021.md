# Day 021 — T6 Performance & Scale

## Topic
GPU acceleration in headless

## Tweet 1/3 — Hook
`--disable-gpu` is the most cargo-culted flag in browser automation. Half of you use it to "save memory," the other half because someone said "it's headless, it doesn't have GPU." Do you know what that flag actually does to your fingerprint?

## Tweet 2/3
Disabling the GPU forces software rendering via SwiftShader. Result: canvas rendering produces a distinct artifact pattern (SwiftShader's rasterization is measurably different from hardware GL). Canvas fingerprinting immediately identifies you as running without GPU — a strong headless signal.

## Tweet 3/3 — Anchor
In 2026, most CI/CD environments support software GPU passthrough (Mesa, SwiftShader, virtual framebuffer). Unless you're in a severely constrained container with no framebuffer, leave the GPU enabled. Faster paint, better stealth, same memory footprint. `--disable-gpu` is almost never the right call.
