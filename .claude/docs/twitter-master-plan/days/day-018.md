# Day 018 — T3 AI Agents

## Topic
Screenshot-driven action validation

## Tweet 1/3 — Hook
Screenshot-every-tick for AI agent feedback is a token disaster. A 1080p PNG at every step, encoded to base64, sent to GPT-4o — that's $0.02 per action and 60% of your context window on pixels. When do you actually need a screenshot?

## Tweet 2/3
Use screenshots for critical state transitions only: did the modal close, did the success toast appear, did the payment complete. `Page.captureScreenshot` with a `clip` parameter lets you capture just the relevant region — send a 100×50px button state, not a full viewport.

## Tweet 3/3 — Anchor
The decision tree: did the CDP action return success? → check DOM for expected element. Element not there? → THEN take a screenshot. Most confirmations can happen without vision. Save screenshots for when the text-based assertion fails.
